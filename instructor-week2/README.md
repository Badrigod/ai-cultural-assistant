# Khayrhaye Living Heritage

## Week 2 Integration

This private practicum prototype combines the AI Cultural Assistant
with Waberi's Digital Artifact Pilot.

### Features
- Five museum artifact records
- Cultural research search
- Linked cultural records
- English and Somali content
- Images and draft audio
- Museum approval safeguards

### Installation

From the extracted package's parent directory, run:

    python -m pip install -r week2-integration/xedho_pilot/requirements.txt
    python -m streamlit run week2-integration/xedho_pilot/app.py

Example artifact page:
http://localhost:8501/?artifact=KHH-001

### Data
Cultural datasets: cultural_data/
Museum records: xedho_pilot/data/
